# Historical Utility experiments

This file is retained as development history only. It does **not** describe
the active Item Rarity 1.0.0-rc1 runtime.

The early generic Container/Melee experiment, generic Scarcity × Utility
promotion matrix, automatic development reports and experimental active model
were superseded by category-specific Utilities and runtime/diagnostic
separation.

For active behavior, use:

- `README.md` for the release overview;
- `docs/rarity-tiers.md` for Strategy D and `FinalRarityTier`;
- `docs/clothing-utility.md` for ClothingUtility V2;
- `docs/food-utility.md`, `docs/fish-utility.md` and
  `docs/firearm-utility.md` for their frozen category models;
- `docs/recipe-crafting-infrastructure.md` for intentionally deferred
  crafting architecture.

Historical diagnostics remain source-available but are explicit dev actions:
they are not loaded, run, or written by the normal pipeline.
